5.5 Package Management

Search, install, update, and remove software with your distribution's package manager; distinguish repositories from the installed package database.

What will you learn in this module?

  • You know Debian-family systems use apt/dpkg and RHEL-family systems use dnf/rpm.
  • You can search, inspect, install, update, and remove packages.
  • You review changes before installation and protect critical packages.

Distributions and package tools

Package managers download software from signed repositories, resolve dependencies, and update the installed package database. Ubuntu and Debian use apt as the high-level tool and dpkg for lower-level queries; Rocky, Alma, and Fedora use dnf and rpm.

The package name for the same software can vary by distribution: Apache HTTP Server is usually httpd on the RHEL family and apache2 on the Debian family. Identify the distribution and correct package name first.

cat /etc/os-release

What is it for?
Shows the distribution name, version, and identifier.
Where is it used?
Before choosing a package command or service name.
Why does it matter?
It confirms whether the system is in the Debian or RHEL family.
cat /etc/os-release

apt search / dnf search

What is it for?
Searches configured repositories by package name or description.
Where is it used?
When you are unsure of the package name.
Why does it matter?
It reduces the chance of installing the wrong package.
dnf search nginx
💡 Tip

Choose apt or dnf for the system family; do not assume the same command is available everywhere.

Search, install, and update

Before installing, inspect the package description and source. apt update refreshes package lists on Debian-family systems; it does not upgrade packages by itself. dnf check-update checks whether updates are available.

Installing packages and system updates requires administrator privileges. Read the confirmation prompt to see which packages will be installed, removed, or updated. Cancel if critical, unexpected changes are listed.

sudo apt install package / sudo dnf install package

What is it for?
Installs a repository package and its required dependencies.
Where is it used?
After verifying the package name and source.
Why does it matter?
It keeps the package database consistent instead of placing downloaded files manually.
sudo dnf install cowsay

sudo apt update / sudo dnf check-update

What is it for?
Refreshes repository package information or checks for updates.
Where is it used?
Before Debian-family installations or when checking for updates.
Why does it matter?
The package manager uses current repository information.
sudo apt update
💡 Tip

apt update refreshes package lists; use apt upgrade separately to upgrade installed packages.

Remove and verify packages

apt remove and dnf remove may affect dependencies when removing a package. apt purge also removes package configuration; autoremove finds dependencies that are no longer needed. Review the proposed removals carefully.

dpkg -l or rpm -qa lists installed packages. These lower-level tools are useful for queries, not installation; use apt or dnf to install or remove packages.

sudo apt remove / sudo dnf remove

What is it for?
Removes a package through the package manager.
Where is it used?
When a test package is no longer needed.
Why does it matter?
It updates the package database and dependencies in a controlled way.
sudo apt remove cowsay

dpkg -l / rpm -qa

What is it for?
Queries the list of installed packages.
Where is it used?
When verifying whether a package is installed.
Why does it matter?
It reports the installation state from the package database.
rpm -qa | grep cowsay
⚠️ Warning

Installing or removing packages changes the system. Practise only in your own VM; do not remove critical packages such as kernel, systemd, SSH, or networking tools. Review the confirmation list.

Do it on your own VM

The real practice happens on real Linux: run the commands in your own virtual machine (VirtualBox, UTM or WSL) and compare the output.

Installing and removing packages changes your system. Work only in your own test VM, never on a production system, and always read confirmation prompts.

Identify the distribution

Check the distribution identifier and which package tools are available.

cat /etc/os-release
command -v apt
dnf --version

Expected output example

The ID= line identifies the distribution; apt or dnf is available for your family.
My output looks different
  • You may not have both package managers; use the one for your distribution.
  • ID or ID_LIKE helps identify the distribution family.

Inspect a package before installing

First display information about the cowsay package. Run only the command appropriate for your distribution.

apt-cache policy cowsay

Expected output example

Candidate or package version
dnf info cowsay

Expected output example

Available Packages or package information
My output looks different
  • Use apt-cache on Debian/Ubuntu and dnf on Rocky/Alma/Fedora.
  • If the package is not found, package lists may be stale or an enabled repository may not contain it.

Install a test package

Install the small cowsay package only in your own test VM, using the command for your distribution. Review the changes in the confirmation prompt.

sudo apt install cowsay

Expected output example

Setting up cowsay or installation complete
sudo dnf install cowsay

Expected output example

Complete! or Installed: cowsay
My output looks different
  • Run only one block: apt for Debian/Ubuntu, dnf for the RHEL family.
  • If the package cannot be found, check the repository and package name before proceeding.

Remove the test package

After the test, remove cowsay with the same package manager and verify the result. Review the proposed removals before confirming.

sudo apt remove cowsay

Expected output example

Removing cowsay or cowsay was removed
sudo dnf remove cowsay

Expected output example

Removing: cowsay or Complete!
My output looks different
  • Use only the command for the distribution family where you installed the package.
  • If unexpected important packages are listed, do not confirm; cancel with n.

Self-test

Which high-level package tool is commonly used on Ubuntu and Debian?

apt manages repositories and package installations on Debian-family systems.

What is the usual Apache HTTP Server package name on the RHEL family?

It is usually httpd on the RHEL family and apache2 on the Debian family.

What does apt update do?

apt update refreshes local repository indexes; use apt upgrade to upgrade installed packages.

What should you do at an installation confirmation prompt?

Dependency resolution can change other packages; review the list before proceeding.

Summary

  • Ubuntu/Debian: apt/dpkg; Rocky/Alma/Fedora: dnf/rpm. Verify your distribution and package names first.
  • apt update refreshes package lists; installation and upgrades are separate operations.
  • Review proposed changes before removal and autoremove; protect critical system packages.

Key terms

repository
A software source where a distribution publishes packages and package information.
dependency
Another package required for a package to install or run.
package manager
A tool that installs, updates, and removes packages and their dependencies.
