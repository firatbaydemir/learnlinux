2.3 Creating and deleting files and folders

Use mkdir, touch, rmdir and rm to build and clean up a file structure in a safe practice area.

What will you learn in this module?

  • You create folders and nested structures with mkdir and mkdir -p.
  • You create empty files with touch, several at once using brace expansion.
  • You know the difference between rmdir and rm -r and check before deleting.

Creating: mkdir and touch

First make a safe practice area: a folder practice in your home directory. Mistakes then only affect it. As a normal user you cannot write to system directories like /etc — that is a protection mechanism.

mkdir creates folders, touch creates empty files. Brace expansion produces several names: touch {a,b,c}.txt creates a.txt b.txt c.txt.

mkdir

What is it for?
Creates a new folder.
Where is it used?
For projects, backups or practice areas.
Why does it matter?
Keeps your files organised.
mkdir practice

mkdir -p

What is it for?
Also creates missing parent folders; no error if the folder exists.
Where is it used?
When building nested structures.
Why does it matter?
One command builds the whole tree.
mkdir -p project/src/code

touch

What is it for?
Creates an empty file or updates an existing file's timestamp.
Where is it used?
When you quickly need an empty file.
Why does it matter?
A starting point for scripts and test files.
touch file1.txt

ls -R

What is it for?
Lists the tree including subfolders.
Where is it used?
When verifying the structure.
Why does it matter?
You see what will be affected before deleting or moving.
ls -R project
💡 Tip

Always verify the result with ls after an action.

Deleting: rm and rmdir

Linux has no trash can on the command line: files removed with rm are gone. So check with ls what you are about to delete.

rmdir removes only empty folders; for a non-empty one it fails and protects you. To delete a folder with its contents you need rm -r. Using rm on a folder without -r gives 'Is a directory'. In this simulator dangerous commands such as rm -rf / are refused.

rm

What is it for?
Deletes files (no undo).
Where is it used?
When cleaning up unneeded files.
Why does it matter?
For space and tidiness — but use with care.
rm delete_me.txt

rmdir

What is it for?
Removes only empty folders.
Where is it used?
When removing empty folders.
Why does it matter?
Stops you from accidentally deleting a full folder.
rmdir project

rm -r

What is it for?
Deletes a folder together with its contents.
Where is it used?
When removing non-empty folders.
Why does it matter?
Clears the tree in one command; use after checking.
rm -r project
💡 Tip

Make it a habit: first ls -R folder, then rm -r folder.

⚠️ Warning

Before pressing ENTER, re-read which folder rm -r will delete. In the wrong directory it destroys your whole project.

⛔ Danger

On a real system never type rm -rf / or rm -rf ~. It causes irreversible data loss; only the simulator refuses it here.

Do it on your own VM

The real practice happens on real Linux: run the commands in your own virtual machine (VirtualBox, UTM or WSL) and compare the output.

On your VM, first create a safe practice folder; never try rm -r where real data lives.

Build a project tree

Build a nested structure in the practice folder and paste the ls -R output.

mkdir -p ~/practice/project/{src,test}
touch ~/practice/project/src/main.c
ls -R ~/practice

Expected output example

/home/student/practice:
project

/home/student/practice/project:
src  test
...
My output looks different
  • The order of ls -R may differ; src and test must appear.
  • Empty folders are separated by a blank line in ls -R output.

See the protection

As a normal user try to create a folder in a system directory and paste the error.

mkdir /etc/practice

Expected output example

mkdir: cannot create directory ‘/etc/practice’: Permission denied
My output looks different
  • On a localised system the message may be translated.
  • If the folder was created you are root; use a normal user and remove it with sudo rmdir /etc/practice.

Clean up

Look inside first, then delete the practice folder. If no errors, press "Done".

ls -R ~/practice
rm -r ~/practice
ls ~/practice

Expected output example

ls: cannot access '/home/student/practice': No such file or directory
My output looks different
  • If you see rm: cannot remove ... Is a directory, you forgot -r.

Self-test

What is true for a file deleted with rm?

The command line has no trash can; deletion is permanent.

What does -p do in mkdir -p a/b/c?

-p (parents) builds the whole path at once and does not complain if the folder already exists.

What happens if you run rmdir on a non-empty folder?

rmdir only removes empty folders. For non-empty ones use rm -r.

Which command is most commonly used to create an empty file?

touch file creates an empty file or updates its timestamp.

Summary

  • mkdir creates folders, mkdir -p nested folders, touch empty files.
  • touch {a,b,c}.txt uses brace expansion to create several files.
  • rmdir removes only empty folders, rm -r non-empty ones; there is no trash.
  • Check with ls before and after every action.

Key terms

directory / folder
A structure that holds files; the same concept.
recursive
An operation that includes subfolders; -r or -R.
brace expansion
The shell turns patterns like {a,b,c} into several words.
timestamp
The time a file was last modified.
