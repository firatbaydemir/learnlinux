3.5 Text Filtering: sort, uniq, cut and tr

Turn raw text into a useful report by sorting lines, counting duplicates, selecting fields and transforming characters.

What will you learn in this module?

  • Sort text and numbers with sort.
  • Collapse or count consecutive duplicates with uniq.
  • Select fields from delimited text with cut.
  • Transform characters with tr and combine tools in pipelines.

Sort lines with sort

sort FILE sorts lines alphabetically or lexically. -r reverses the order; -n sorts numeric values rather than text. For example, a plain text sort may place 100 before 2.

sort prints its result and does not change the source file. Redirect the output to a different file if you want to keep the sorted result.

sort

What is it for?
Sorts lines as text.
Where is it used?
When putting a list in alphabetical order.
Why does it matter?
Groups similar lines together.
sort data/fruits.txt

sort -r

What is it for?
Reverses the sort order.
Where is it used?
When you want later values first.
Why does it matter?
Produces the reverse of the same ordering.
sort -r data/fruits.txt

sort -n

What is it for?
Sorts lines by numeric value.
Where is it used?
For files with one number per line.
Why does it matter?
Places values such as 2 and 100 in numeric order.
sort -n data/numbers.txt
💡 Tip

By default, sort compares text. Use -n for numbers, and check the first lines with head if needed.

Collapse duplicates with uniq

uniq collapses only identical adjacent lines. If duplicates occur in different parts of a file, sort them first to bring them together.

uniq -c prefixes each unique line with its count. This is useful for simple frequency reports.

uniq

What is it for?
Collapses consecutive identical lines into one.
Where is it used?
When removing duplicates from a sorted list.
Why does it matter?
Leaves one copy of each value.
sort data/fruits.txt | uniq

uniq -c

What is it for?
Collapses consecutive duplicates and prints their counts.
Where is it used?
When calculating how often each value occurs.
Why does it matter?
Shows each value and its frequency together.
sort data/fruits.txt | uniq -c
⚠️ Warning

uniq does not search for duplicates across the whole file; it catches only adjacent repeats. The common pattern is sort | uniq.

Select fields with cut and transform characters with tr

cut -dDELIMITER -fFIELD selects fields from delimited lines. CSV uses commas, while /etc/passwd uses colons. Select multiple fields with a comma-separated list such as -f1,3.

tr SET1 SET2 transforms characters from standard input. For example, you can convert ASCII lowercase letters to uppercase. cut, sort, uniq and tr use stdin and stdout, so they can be combined with pipes.

cut -d, -f1

What is it for?
Selects the first field from comma-separated lines.
Where is it used?
When extracting a column from a CSV file.
Why does it matter?
Removes columns you do not need.
cut -d, -f1 data/employees.csv

cut -d, -f1,3

What is it for?
Selects the first and third fields.
Where is it used?
When you need more than one column.
Why does it matter?
Keeps only the required data.
cut -d, -f1,3 data/employees.csv

tr 'a-z' 'A-Z'

What is it for?
Converts ASCII lowercase letters to uppercase.
Where is it used?
When standardizing the letter case of text.
Why does it matter?
Transforms characters within a pipeline.
echo hello | tr 'a-z' 'A-Z'
💡 Tip

For text separated by variable amounts of whitespace, awk may be more flexible than cut; here we focus on fixed delimiters.

Combine tools in a pipeline

Text filters are small and focused. For example, select a status-code field from a log, sort it and count it with uniq -c. Check the result on screen, then save it to a report with >.

Order matters: sort | uniq -c counts duplicates, then sort -rn sorts by count from highest to lowest.

sort | uniq -c | sort -rn

What is it for?
Counts values and sorts them from most to least frequent.
Where is it used?
When finding common values in logs or lists.
Why does it matter?
Combines small tools into a report.
cut -d' ' -f2 data/access.log | sort | uniq -c | sort -rn

cut -d, -f2

What is it for?
Passes the selected field from CSV into a pipe.
Where is it used?
When preparing one column for another filter.
Why does it matter?
Keeps each tool focused on one task.
cut -d, -f2 data/employees.csv | sort | uniq
⚠️ Warning

> overwrites the existing contents of its target. Do not write over the source file; choose a separate report filename.

Do it on your own VM

The real practice happens on real Linux: run the commands in your own virtual machine (VirtualBox, UTM or WSL) and compare the output.

These filters only read input on your VM. Use separate filenames in your home directory for output reports.

Numeric sort

Sort the user IDs in /etc/passwd numerically and paste the first few lines.

cut -d: -f3 /etc/passwd | sort -n | head -n 5

Expected output example

0
1
2
My output looks different
  • The IDs depend on the distribution; they should be in increasing numeric order.

Select a CSV field

Extract the name field from the report CSV in your home directory. If it is not present, replace the path with one of your CSV files.

cut -d, -f1 ~/Documents/list.csv

Expected output example

name
alice
bob
My output looks different
  • If your CSV uses a different delimiter, change -d. The first line may be a header.

Count frequencies

Count login shell fields in /etc/passwd and paste the frequency table.

cut -d: -f7 /etc/passwd | sort | uniq -c | sort -rn

Expected output example

\d+\s+\S+
My output looks different
  • Counts vary by distribution. Make sure sort comes before uniq -c.

Create a small report

Prepare sample status codes in your home directory, sort and count them, then show the report.

mkdir -p ~/lab && cd ~/lab && printf '200\n404\n200\n500\n200\n' > status.txt && sort status.txt | uniq -c | sort -rn > status_report.txt && cat status_report.txt
My output looks different
  • If status_report.txt is empty, check status.txt and the redirection order. Do not overwrite the source.

Self-test

Which option sorts numeric lines by their numeric values?

sort -n sorts numerically.

Why is uniq usually used after sort?

Sorting brings identical values next to each other so uniq can collapse them.

What does cut -d, -f2 file.csv select?

-d, sets the delimiter to a comma and -f2 selects the second field.

What does tr 'a-z' 'A-Z' do?

tr transforms character sets; this example converts ASCII lowercase letters to uppercase.

Summary

  • sort sorts text; use sort -n for numbers and sort -r for reverse order.
  • uniq collapses only adjacent duplicates, so sorting first is usually necessary.
  • uniq -c reports the count for each unique line.
  • cut -dDELIMITER -fFIELD selects fields from delimited lines.
  • tr transforms characters; combine small tools with pipes and write reports to separate files.

Key terms

filter
A command that reads input and writes selected or transformed output.
delimiter
A character that separates fields in a line.
field
One column of a line split by a delimiter.
frequency table
A list showing how often each value occurs.
