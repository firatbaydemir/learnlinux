1.3 Help and discovery

Use man, --help, which, type, find and history to research an unfamiliar command on your own, without the internet.

What will you learn in this module?

  • You open a man page, navigate it, search it and quit; you recognise the section numbers (1, 5, 8).
  • You get a quick summary with --help and help, and read SYNOPSIS notation ([ ], | and ...).
  • You find where a command is and what type it is with which and type, and search for files with find.
  • You review old commands with history and systematically resolve 'command not found' errors (exit code 127).

man: manual pages

Linux has hundreds of commands; even professionals don't memorise them all, they know where to look. The most reliable source is the system's own manual, the man pages: man ls.

The page opens in a pager: Space goes down a page, b goes up, /kernel + Enter searches the text, n jumps to the next match, q quits. Page headings are always the same: NAME (short name), SYNOPSIS (usage form), DESCRIPTION, OPTIONS, EXAMPLES, SEE ALSO.

The manual is split into sections: 1 = user commands, 5 = file formats (e.g. /etc/passwd), 8 = administration commands. The same name can appear in several sections: man passwd shows the command, man 5 passwd shows the file format. In the simulator the pages are short and section numbers are not supported; on a real VM you see the full page.

man

What is it for?
Opens the manual page of a command.
Where is it used?
When learning a new command or option.
Why does it matter?
It is accurate information that ships with your system and matches its version.
man ls

man <section>

What is it for?
Opens a specific manual section.
Where is it used?
When the same name is both a command and a file format.
Why does it matter?
You reach the right page directly.
man 5 passwd

whatis

What is it for?
Gives a one-line description of a command.
Where is it used?
To quickly remember what a command does.
Why does it matter?
You get a summary without opening the page.
whatis ls

apropos

What is it for?
Searches manual pages by keyword.
Where is it used?
When you don't know the command's name but know what it does.
Why does it matter?
Searching for 'copy file' lets you find cp.
apropos copy
💡 Tip

If you get lost in a page, leave with q. To search, type /, enter the word, press Enter; the next match is n.

⚠️ Warning

whatis and apropos rely on an index (mandb); on freshly installed minimal systems they may return nothing. In that case run sudo mandb.

--help and help: quick summary

If you don't want to read the whole manual, ls --help prints a short usage summary. If the output is long, limit it with | head or | less: ls --help | head -n 5.

Shell built-in commands like cd have no separate program, so man cd sometimes doesn't exist. For them Bash has the help command: help cd. On its own, help lists the known commands (in the simulator this list is short).

Quick rule: for an external program use --help first, man for details; for a shell built-in use help.

--help

What is it for?
Prints a short usage summary of the command.
Where is it used?
To quickly recall an option.
Why does it matter?
It is much faster than man.
ls --help

help

What is it for?
Gives help about Bash's own (built-in) commands.
Where is it used?
For commands like cd, type, history.
Why does it matter?
These commands may not have a separate man page.
help

less

What is it for?
Shows long output page by page.
Where is it used?
For long --help or file output.
Why does it matter?
The navigation keys are the same as in man.
ls --help | less
💡 Tip

When help is printed, don't miss the top line: the Usage: line gives you the usage form.

Reading SYNOPSIS notation

The SYNOPSIS line gives the command's 'pattern'. Example: ls [OPTION]... [FILE].... Read it like this:

Anything inside [ ] is optional. ... means the previous part can be written more than once. a | b means either a or b. < > or UPPERCASE (FILE, DIR) is a value you substitute. Parts written in bold are typed exactly as shown.

Example: cp [OPTION]... SOURCE... DEST → options are optional, at least one source and one destination are required. ls also works with no arguments because everything is in square brackets.

ls --help

What is it for?
Shows the usage pattern (Usage).
Where is it used?
To learn the order of arguments.
Why does it matter?
If you can read the pattern, you can figure out any new command.
ls --help

man cat

What is it for?
Opens the page that contains the SYNOPSIS section.
Where is it used?
A simple example to practise with.
Why does it matter?
You see square brackets and ... in a real page.
man cat
💡 Tip

To find what is mandatory, look at the parts outside the square brackets.

which and type: where is the command?

When you type a command, the shell searches the directories in the PATH variable in order. which ls prints the path it finds (e.g. /usr/bin/ls).

type is more informative: it tells you whether the command is an external program, a shell built-in (builtin), an alias or a function. type cd → cd is a shell builtin. Use it to understand which one runs when several commands share the same name.

To see the contents of PATH, use echo $PATH. alias and command -v also work on a real VM, but not in the simulator.

which

What is it for?
Shows the file path of the command.
Where is it used?
To find out where a program is installed.
Why does it matter?
You verify that you are running the right version.
which ls

type

What is it for?
Tells the type of the command (program, builtin, alias).
Where is it used?
When investigating unexpected behaviour.
Why does it matter?
You tell a builtin from an external program.
type cd

echo $PATH

What is it for?
Prints the directories where commands are searched.
Where is it used?
When investigating 'command not found'.
Why does it matter?
You see whether the program's directory is in PATH.
echo $PATH

command -v

What is it for?
Prints the path/name if the command exists; stays silent otherwise.
Where is it used?
In scripts, to check 'is it installed?'.
Why does it matter?
It is a portable existence check.
command -v ls

alias

What is it for?
Lists defined shortcuts.
Where is it used?
To understand where commands like ll come from.
Why does it matter?
You see the source of what type calls an 'alias'.
alias
💡 Tip

If a command behaves strangely, first check its type with type command.

find: file search basics

find <start> <conditions> walks a directory tree and prints what matches the conditions. The two most common conditions: -name (by name) and -type (f file, d directory).

Put the wildcard in quotes: find . -name "*.txt". Without quotes the shell expands the pattern itself first and the result is misleading. The start point . is the current directory, ~ is home.

You can count the result with | wc -l and save it with > file. -maxdepth 1 limits the depth on a real system (the simulator ignores it).

find

What is it for?
Searches the directory tree for files matching a condition.
Where is it used?
When you forgot where a file is.
Why does it matter?
It scans the tree by name, type or size.
find . -name "*.txt"

find -type

What is it for?
Finds only files (f) or directories (d).
Where is it used?
To count directories separately.
Why does it matter?
You narrow the result.
find ~ -type d

find | wc -l

What is it for?
Gives the number of items found.
Where is it used?
To know how many matches there are.
Why does it matter?
You get a number without reading a long list.
find ~ -name "*.txt" | wc -l
💡 Tip

To hide error messages on a real system, add 2>/dev/null.

⚠️ Warning

Don't delete with find ... -delete or -exec rm; first view the list with plain find, then decide.

history: past commands

history lists the commands you typed in this and earlier sessions with numbers. If it is long, take the last ten commands with history | tail -n 10.

In real Bash, up arrow brings back the previous command, Ctrl+R searches the history, !! re-runs the last command, !42 re-runs command number 42. The simulator does not support !!; the arrow keys work.

Commands that contain secrets (passwords) are written to the history; don't forget that.

history

What is it for?
Lists past commands with numbers.
Where is it used?
To remember what you typed earlier.
Why does it matter?
You find a long command without retyping it.
history

history | tail

What is it for?
Shows only the most recent commands.
Where is it used?
In a long history.
Why does it matter?
The list stays short.
history | tail -n 5

!!

What is it for?
Re-runs the last command.
Where is it used?
sudo !! for a privileged retry.
Why does it matter?
It saves time.
!!
💡 Tip

Press Ctrl+R and type part of the command: Bash brings back the match.

Dealing with 'command not found'

If you type a command that doesn't exist you get nosuchcmd: command not found and the exit code is 127: nosuchcmd; echo $? → 127. Code 127 means 'command not found'.

Systematic check: (1) Is it a typo? (ls instead of lss) (2) Upper/lower case: Linux is case-sensitive. (3) Check whether it exists with type command. (4) If the program isn't installed, install the package (Ubuntu sudo apt install, Rocky/Alma sudo dnf install). (5) If it is installed, check the directory with echo $PATH.

This differs from the 'No such file or directory' error: there the command was found but the file you gave doesn't exist.

echo $?

What is it for?
Prints the exit code of the last command.
Where is it used?
When checking whether a command succeeded.
Why does it matter?
0 means success, 127 means command not found.
nosuchcmd; echo $?

type

What is it for?
Does the command exist, and where?
Where is it used?
The first check after an error.
Why does it matter?
It weeds out typos.
type nosuchcmd
💡 Tip

On a real system Ubuntu sometimes suggests 'Command 'x' not found, did you mean...'; read the suggestion carefully.

Do it on your own VM

The real practice happens on real Linux: run the commands in your own virtual machine (VirtualBox, UTM or WSL) and compare the output.

Run the following commands on your VM (Ubuntu, Rocky, Alma or WSL). There is no destructive command; still, remember to leave the pager (man) with q.

Open a manual page

Open man ls, search for long with /, leave with q. Then paste the first lines.

man ls | head -n 5

Expected output example

LS(1)    User Commands

NAME
       ls - list directory contents
My output looks different
  • If your language is Turkish/German the headings may be translated.
  • If you get 'No manual entry', the manual package is missing: sudo apt install man-db or sudo dnf install man-db.

--help summary

Paste the first lines of the ls --help output.

ls --help | head -n 5

Expected output example

Usage: ls [OPTION]... [FILE]...
List information about the FILEs (the current directory by default).
My output looks different
  • On macOS or BusyBox the --help format may differ; run it on a Linux VM.

Command types

Paste the type and path of the cd, ls and which ls commands.

type cd
type ls
which ls

Expected output example

cd is a shell builtin
ls is aliased to `ls --color=auto'
/usr/bin/ls
My output looks different
  • ls may be an alias (for colour on Ubuntu/Rocky); this is normal.
  • On some distributions you get /bin/ls (/bin is linked to /usr/bin).

Search with find

Find the .txt files in your home. Since the output is personal, just say 'Done'.

find ~ -maxdepth 2 -name "*.txt" 2>/dev/null
My output looks different
  • If there is no output, you have no .txt files in your home: first create one with touch ~/notes.txt.

whatis and apropos

Search for the one-line description of ls and for commands containing 'copy'.

whatis ls
apropos copy | head -n 5

Expected output example

ls (1) - list directory contents
cp (1) - copy files and directories
My output looks different
  • If you see 'nothing appropriate', there is no index: run sudo mandb and try again.
  • On Ubuntu/Rocky the apropos output may have a different number of lines.

command not found

Run a command that doesn't exist and paste the exit code.

nosuchcmd; echo $?

Expected output example

bash: nosuchcmd: command not found
127
My output looks different
  • Ubuntu may suggest 'Command 'nosuchcmd' not found, did you mean...'; the last line should still be 127.
  • If you use Zsh the message is 'zsh: command not found: nosuchcmd'.

Look at the history

List your last five commands.

history | tail -n 5

Expected output example

  498  which ls
  499  nosuchcmd
  500  history | tail -n 5
My output looks different
  • The numbers will be different; this is normal.
  • In a freshly opened terminal the list may be short.

Manual sections

Open the section 5 page describing the format of the /etc/passwd file and paste the first lines.

man 5 passwd | head -n 5

Expected output example

PASSWD(5)   File Formats Manual

NAME
       passwd - password file
My output looks different
  • man passwd (section 1) is a different page: the password-changing command.
  • If the page is missing, the man-db or man-pages package is absent.

Self-test

Which keys are used to search for text in a man page and to quit the page?

/word searches, n goes to the next match, q quits.

In the pattern ls [OPTION]... [FILE]..., what do [ ] and ... mean?

Square brackets mean optional, the three dots show that the previous part can be repeated.

What is the number in the output of nosuchcmd; echo $??

In the 'command not found' case Bash returns 127 as the exit code.

With which command do you see that cd is not an external program?

The output of type cd is cd is a shell builtin; that is, it is inside Bash.

Summary

  • man command is the detailed manual, command --help a short summary, help is for shell built-ins.
  • In man: / searches, n next, q quits; sections: 1 commands, 5 file formats, 8 administration.
  • SYNOPSIS: [ ] optional, ... repetition, | or.
  • which shows the path, type shows the type; find . -name "*.txt" searches for files.
  • history lists the past; command not found has exit code 127.

Key terms

man page
The manual page of a command that ships with the system.
SYNOPSIS
The man section showing the command's usage pattern.
builtin
A command embedded in Bash that has no separate program.
PATH
The list of directories where commands are searched.
exit code
The number a command leaves when it finishes; 0 is success, 127 is command not found.
pager
A program that shows long text page by page (less).
