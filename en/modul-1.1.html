Home / Level 1

1.1 Navigating the Terminal: pwd, ls, cd

See where you are, get to know your surroundings, reach your target: move around the file system safely with pwd, ls and cd.

What will you learn in this module?

  • You see your current directory with pwd and know that the ~ in the prompt is the home directory.
  • You list directory contents with ls and its options (-l, -a, -h) and find hidden files.
  • You move between directories with cd using the shortcuts ~, -, .. and ..
  • You know the difference between absolute and relative paths, read the columns in ls -l output and use Tab completion.

Where am I? pwd and the home directory

In Linux everything lives in a single tree whose root is /. In the terminal you are always somewhere in this tree: your current working directory. Most commands act there unless told otherwise.

pwd (print working directory) prints your current directory as a full path. A command run in the wrong directory can cause data loss, so check with pwd especially before deleting or copying.

When you log in you land in your home directory, such as /home/student. It is written ~ for short; that is the ~ in the prompt.

pwd

What is it for?
Shows your current directory as a full path.
Where is it used?
Before any operation, especially deleting and copying.
Why does it matter?
Prevents wrong operations in the wrong directory.
pwd

echo ~

What is it for?
Prints the expansion of the ~ shortcut, i.e. the full path of your home directory.
Where is it used?
When you want to know the path of your home directory.
Why does it matter?
~ is expanded by the shell; commands see the real path.
echo ~
💡 Tip

A ~ in the prompt means you are in your home directory; in any other directory only the last folder name, such as Documents, is shown.

What is inside? ls

ls lists the contents of your current directory. If you give it a directory as a path, it lists that one without entering it: ls /etc. Look first, then decide.

Options start with - and can be combined: -l detailed list, -a including hidden files, -h human-readable sizes (K, M, G). ls -lah gives all three at once.

ls

What is it for?
Lists the files and folders in your current directory.
Where is it used?
After entering a directory or when checking whether something exists.
Why does it matter?
Working where you don't know what is there is dangerous.
ls

ls /etc

What is it for?
Lists the contents of the given directory without entering it.
Where is it used?
To look at another directory.
Why does it matter?
You look without changing your working directory.
ls /etc

ls -a

What is it for?
Also shows hidden files whose names start with a dot.
Where is it used?
When looking for configuration files.
Why does it matter?
Hidden files do not appear in normal ls output.
ls -a

ls -lh

What is it for?
Detailed list; prints sizes as K/M/G.
Where is it used?
When looking at file sizes.
Why does it matter?
Easier than reading byte counts.
ls -lh ~
💡 Tip

If ls output is long in a directory with many files, use ls -l | head to see the first lines.

Reach your target: cd

cd (change directory) changes your working directory. On success it prints nothing; you see the result in the prompt or with pwd. If the directory does not exist, you get an error.

Shortcuts: cd (without an argument) and cd ~ take you to your home directory, cd .. goes up one directory, cd - returns to the previous directory. . is the current directory; cd . stays where you are.

Case matters: Documents and documents are different names. If a name contains a space, use quotes: cd "My Files".

cd Documents

What is it for?
Enters the Documents folder in your current directory.
Where is it used?
When going down into a subfolder.
Why does it matter?
Relative path: starts from where you are.
cd Documents

cd ..

What is it for?
Goes up one directory.
Where is it used?
When leaving a folder.
Why does it matter?
.. points to the parent directory in every directory.
cd ..

cd ~

What is it for?
Goes to the home directory.
Where is it used?
When you are lost.
Why does it matter?
Works wherever you are.
cd ~

cd -

What is it for?
Returns to the previous directory and prints its path.
Where is it used?
When switching back and forth between two directories.
Why does it matter?
Saves you from retyping long paths.
cd -

cd

What is it for?
Typed without an argument, goes to the home directory.
Where is it used?
To get home quickly.
Why does it matter?
Same as cd ~, but shorter.
cd
💡 Tip

If you get lost, type cd, then check with pwd: you are back in your home directory.

Absolute and relative paths

An absolute path starts with / and is the full address from the root: /usr/bin. It always leads to the same place regardless of where you are. ~/Documents also counts as absolute, because ~ expands to a full path.

A relative path does not start with / and is computed from your current directory: Documents, ../Downloads, ./notes.txt. The same spelling leads to different places in different directories.

.. is the parent directory and . is the current directory; they can be chained: cd ../.. goes up two directories. When you are in /usr/bin, cd ../.. takes you to the root /.

cd /usr/bin

What is it for?
Goes straight to /usr/bin using an absolute path.
Where is it used?
When heading to a target regardless of where you are.
Why does it matter?
The result is always the same.
cd /usr/bin

cd ../..

What is it for?
Goes up two directories.
Where is it used?
When leaving a deep folder quickly.
Why does it matter?
In relative paths .. can be chained.
cd ../..
💡 Tip

If you are unsure, type the absolute path; for short distances a relative path is faster.

Hidden files

Files and folders whose names start with a dot are hidden: .bashrc, .profile, .config. Normal ls does not show them, ls -a does. Settings are usually kept in these files.

In ls -a output you see two special entries: . (the current directory) and .. (the parent directory). They are not real files but shortcuts present in every directory.

ls -a ~

What is it for?
Lists everything in the home directory, including hidden files.
Where is it used?
When looking for configuration files.
Why does it matter?
Files like .bashrc only show up this way.
ls -a ~

ls -A

What is it for?
Shows hidden files without . and ...
Where is it used?
For a cleaner list (on a real VM).
Why does it matter?
Same as -a, but without the two shortcut entries.
ls -A ~
⚠️ Warning

Do not delete or damage configuration files such as .bashrc and .profile; your shell environment may break.

Reading ls -l output

ls -l gives one line per file. Example: -rw-r--r-- 1 student student 35 Nov 12 10:32 notes.txt. From left to right:

1st character: type. - regular file, d directory, l symbolic link. Next 9 characters: permissions (rw-r--r--: owner reads/writes, group and others read). Number: link count. Two names: owner user and group. Number: size in bytes. Date: last modification. Last: name.

The total line at the top is the sum of disk blocks used. You will see the details of permissions in later modules.

ls -l

What is it for?
Detailed list showing type, permissions, owner, size, date and name.
Where is it used?
When checking a file's owner or permissions.
Why does it matter?
All the basic information about a file in one line.
ls -l

ls -ld ~

What is it for?
Shows a directory itself (not its contents) in detail.
Where is it used?
When checking a directory's permissions or owner.
Why does it matter?
Without -d, ls looks inside the directory.
ls -ld ~
💡 Tip

If the line starts with d it is a folder, if it starts with - it is a file.

Tab completion

Don't type long names by hand in the terminal: type the first letters of the name and press Tab. If there is a single match, the shell completes the name. If there are several matches, press Tab twice; the options are listed.

It works for commands as well as file and folder names. It saves time and prevents typos: if Tab does not complete, that name does not exist or you are in the wrong directory.

Extra shortcut: the ↑/↓ keys recall previous commands. These features work in a real shell (on your VM).

cd Doc + Tab

What is it for?
Typing Doc and pressing Tab completes it to Documents/.
Where is it used?
In every command, when typing file and folder names.
Why does it matter?
You type less and make fewer mistakes.
cd Doc
💡 Tip

Make it a habit: press Tab before typing a name from start to finish.

Do it on your own VM

The real practice happens on real Linux: run the commands in your own virtual machine (VirtualBox, UTM or WSL) and compare the output.

Run these tasks on your own VM (Ubuntu, Rocky, Alma or WSL). They are all read-only; they change nothing.

Where am I?

Open the terminal; print your current directory and the path of your home directory, and paste the output.

pwd
echo ~

Expected output example

/home/student
/home/student
My output looks different
  • If your username is not student, your own name appears in the path; that is normal.
  • If the output is /root, you are running as root; switch to a normal user.

Find hidden files

List your home directory including hidden files and find the .bashrc file.

ls -a ~

Expected output example

.  ..  .bash_logout  .bashrc  .profile  Desktop  Documents ...
My output looks different
  • You may see many hidden folders (.cache, .config); that is normal.
  • On WSL, .bashrc is still in the home directory; make sure you look under ~.

Absolute, relative and cd -

Go to /var/log using an absolute path, go up with .., return with cd - and print the paths.

cd /var/log
pwd
cd ..
pwd
cd -
cd /etc
pwd

Expected output example

/var/log
/var
/var/log
/etc
My output looks different
  • cd - also prints the previous path by itself; seeing an extra line is normal.
  • If /var/log does not exist (very minimal image), try cd /usr/bin instead.

Read ls -l

List the file /etc/passwd in detail; read its type, permissions, owner and size.

ls -l /etc/passwd

Expected output example

-rw-r--r-- 1 root root 1234 Nov 12 10:32 /etc/passwd
My output looks different
  • A . or + at the end of the permissions (SELinux/ACL) is normal.
  • Size and date vary depending on your system.

Tab completion

Type cd Doc and press Tab without pressing Enter; it should complete to Documents/. Then type cd ~/ and press Tab twice to see the list. When done, say "Done".

cd Doc<Tab>
My output looks different
  • If it does not complete, the Documents folder does not exist or you are not in your home directory; check with pwd.
  • On some minimal systems the bash-completion package is needed for completion.

Self-test

What does the pwd command do?

pwd (print working directory) prints the working directory.

What does cd .. do?

.. is the parent directory; use cd ~ for home and cd - for the previous one.

Which one is used to see hidden files?

-a shows files whose names start with a dot.

In ls -l output, what does it mean if a line starts with d?

The first character shows the type: d directory, - file, l symbolic link.

Summary

  • pwd tells you where you are, ls what is there, cd where to go.
  • ~ is the home directory, .. the parent directory, . the current directory, cd - the previous directory.
  • An absolute path starts with /; a relative path is computed from your current directory.
  • ls -a shows hidden files, ls -l shows type, permissions, owner, size and date.
  • Complete with Tab; mind upper and lower case.

Key terms

working directory
The directory you are currently in, where commands run by default.
home directory
The directory that belongs to the user; abbreviated ~, for example /home/student.
absolute path
A full address starting from the / root.
relative path
A path starting from your current directory.
hidden file
A file whose name starts with a dot, visible with ls -a.
Tab completion
Typing the start of a name and pressing Tab to have the shell complete it.
