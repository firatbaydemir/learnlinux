3.6 sed and awk

Use sed to replace, delete and select text line by line; use awk to split lines into fields (columns), calculate and summarize log files.

What will you learn in this module?

  • You use sed with s/old/new/, the g flag, -n + p, addresses/ranges and d.
  • You know that sed -i changes a file permanently and make a backup first (-i.bak).
  • You select fields with awk ($1, $NF, -F), write conditions and compute sums and averages with BEGIN/END.
  • You count values in log files with awk arrays and combine awk in pipelines with cut, sort, uniq.

sed: substitution (s///)

sed (stream editor) reads text line by line, applies a command and prints the result. It does not change the file; only -i does that (third section).

The most common command is s/search/replace/. By default only the first match on each line is replaced; add g (global) for all of them: s/cat/dog/g.

The delimiter does not have to be /. For paths like /usr/local use |: s|/usr/local|/opt|. A & in the replacement stands for the match itself; write \& for a literal &.

sed 's/old/new/'

What is it for?
Replaces the first match on each line.
Where is it used?
For a quick text fix.
Why does it matter?
You see the result without touching the file.
sed 's/cat/hamster/' pets.txt

sed 's/old/new/g'

What is it for?
Replaces all matches on the line.
Where is it used?
When a word must change everywhere.
Why does it matter?
Without g the second match on a line stays.
sed 's/cat/dog/g' pets.txt

sed 's|a|b|'

What is it for?
Uses | as delimiter; readable for paths containing /.
Where is it used?
When replacing paths and URLs.
Why does it matter?
No \/ escapes needed.
sed 's|/usr/local|/opt|' paths.txt

sed -e ... -e ...

What is it for?
Applies several sed commands in order.
Where is it used?
When one pass needs several changes.
Why does it matter?
The file is read only once.
sed -e 's/it/IT/g' -e 's/hr/HR/g' employees.csv
💡 Tip

With -E (extended regex) +, ?, | and ( ) work without escapes: sed -E 's/[0-9]+/N/g' access.log.

⚠️ Warning

The pattern is a regular expression: . means any character. To match a dot write \., otherwise s/1.2/X/ also replaces 102.

sed: selecting and deleting lines

By default sed prints every line. -n turns that off; then p (print) prints only the lines you want. You pick lines with an address: a number (2p), a range (1,3p), the last line ($p) or a regex (/404/p).

d (delete) drops the line from the output. /^#/d removes comment lines, /^$/d blank lines, 1d the header line. All of this affects only the output; the file stays the same. To save the result, redirect: sed '/^#/d' server.conf > clean.conf.

sed -n 'Np'

What is it for?
Prints only line N.
Where is it used?
To view a specific line of a big file.
Why does it matter?
Shorter than head | tail.
sed -n '2p' pets.txt

sed -n 'A,Bp'

What is it for?
Prints lines A through B; $ is the last line.
Where is it used?
To look at one section of a file.
Why does it matter?
You get the range with one command.
sed -n '2,4p' employees.csv

sed '/regex/d'

What is it for?
Deletes matching lines from the output.
Where is it used?
When stripping comment or blank lines.
Why does it matter?
Produces the clean version of a config file.
sed '/^#/d' server.conf

sed '1d'

What is it for?
Skips the first line (e.g. a CSV header).
Where is it used?
Before processing data that has a header.
Why does it matter?
Later tools do not mistake the header for data.
sed '1d' employees.csv
💡 Tip

-n and p always go together. Alone, sed '2p' prints line 2 twice (once automatically, once by p).

sed -i: editing a file in place

sed -i writes the result not to the screen but into the file itself. There is no undo and no trash can: a wrong regex damages the file permanently.

Rule: run without -i first and check the output, then run with a backup. sed -i.bak '...' file keeps the original as file.bak and works in both GNU (Linux) and BSD (macOS) sed.

GNU/BSD difference: on Linux sed -i 's/a/b/' f is enough. On macOS -i requires a suffix; for no backup write sed -i '' 's/a/b/' f. If the same command behaves differently on two systems, this is why.

sed -i.bak

What is it for?
Edits the file in place and saves the original as .bak.
Where is it used?
When changing configuration files.
Why does it matter?
If something goes wrong you restore from the backup.
sed -i.bak 's/8080/9090/' server.conf

cp file file.bak

What is it for?
Makes a manual backup.
Where is it used?
Before changing several files.
Why does it matter?
Leaves you a way back after -i.
cp app.conf app.conf.bak

diff old new

What is it for?
Shows the difference between two files.
Where is it used?
When verifying the change.
Why does it matter?
You see whether only the intended line changed.
diff server.conf.bak server.conf
⚠️ Warning

sed -i cannot be undone. On production systems take a backup first. For several files (sed -i ... *.conf) test on one file without -i first.

⛔ Danger

With a wrong pattern, sed -i 's/.*//' file empties the whole file. Take a snapshot of your VM before destructive experiments.

awk: fields and conditions

awk splits each line into fields at whitespace: $1 is the first, $2 the second, $NF the last field, $0 the whole line. Change the separator with -F: for CSV use -F,.

A program has the form pattern { action }. Without a pattern it applies to every line; with one, only to matching lines: $3 > 5000 or /404/. Without an action the line is printed. NR is the line number, NF the field count; NR>1 skips the header.

BEGIN { } runs once before the first line, END { } once after the last. Ideal for sums and averages: { s += $3 } END { print s }. Use printf for formatted output; you write the line ending yourself (\n).

awk '{print $1}'

What is it for?
Prints the first field of each line.
Where is it used?
To take a column from logs or command output.
Why does it matter?
cut trips over varying spaces, awk does not.
awk '{print $1}' access.log

awk -F, '...'

What is it for?
Sets the field separator to ,.
Where is it used?
For CSV and :-separated files.
Why does it matter?
The only way to get the values into the right fields.
awk -F, 'NR>1 {print $1, $3}' employees.csv

awk 'condition'

What is it for?
Prints only lines that satisfy the condition.
Where is it used?
When selecting values over a threshold or error codes.
Why does it matter?
Allows numeric comparisons grep cannot do.
awk -F, 'NR>1 && $3 > 5000 {print $1}' employees.csv

awk '... END {...}'

What is it for?
Prints the result after the last line.
Where is it used?
For sums, averages, counters.
Why does it matter?
One pass gives you the summary.
awk -F, 'NR>1 {s+=$3} END {print s}' employees.csv
💡 Tip

Always put the awk program in single quotes; otherwise the shell expands $1 itself and awk gets an empty program.

awk: counting and log analysis

awk arrays are associative (key → value) and need no declaration. c[$2]++ increments the counter for each status code; in the END block for (k in c) prints them all. The order is undefined, so append sort.

The pattern combines with pipes: ps aux | awk 'NR>1 {print $1}' | sort | uniq -c shows how many processes each user has. cut -d' ' -f2 access.log | sort | uniq -c works too, but with irregular spacing awk is safer.

awk '{c[$2]++} END {for (k in c) print k, c[k]}'

What is it for?
Counts how often each value in field two occurs.
Where is it used?
When counting per HTTP status code or IP.
Why does it matter?
Summarizes a log with one command.
awk '{c[$2]++} END {for (k in c) print k, c[k]}' access.log | sort

awk '{print $NF}'

What is it for?
Prints the last field of each line.
Where is it used?
For lines with a varying number of fields.
Why does it matter?
You do not need to know the last column's number.
awk '{print $NF}' access.log

awk 'BEGIN {...}'

What is it for?
Runs once before the file is read.
Where is it used?
For headings or initial values.
Why does it matter?
Adds a title to the report output.
awk 'BEGIN {print "ip status"} {print $1, $2}' access.log

awk '{printf ...}'

What is it for?
C-style formatted output.
Where is it used?
For aligned or decimal numbers.
Why does it matter?
print does not give you control of format and line ending.
awk -F, 'NR>1 {printf "%s earns %d\n", $1, $3}' employees.csv
💡 Tip

Average: END {print s/(NR-1)} (with a header) or a separate counter (n++). Watch out for division by zero on an empty file.

Do it on your own VM

The real practice happens on real Linux: run the commands in your own virtual machine (VirtualBox, UTM or WSL) and compare the output.

Run these commands on your own Ubuntu/Rocky/Alma VM. Everything stays in ~/lab and your own test files. sed and awk come preinstalled on these distributions (GNU versions).

Create the test files

Create the following four test files in ~/lab with printf and paste the line counts.

mkdir -p ~/lab && cd ~/lab
printf 'cat\ndog\nbird\ncat\nfish\n' > pets.txt
printf 'name,dept,salary\nanna,it,5200\nben,hr,4100\ncara,it,6100\ndan,ops,3900\n' > employees.csv
printf '# server config\nport=8080\n# debug off\ndebug=false\nhost=localhost\n' > server.conf
printf '10.0.0.1 200\n10.0.0.2 404\n10.0.0.1 200\n10.0.0.3 500\n10.0.0.2 200\n' > access.log
wc -l pets.txt employees.csv server.conf access.log

Expected output example

  5 pets.txt
  5 employees.csv
  5 server.conf
  5 access.log
 20 total
My output looks different
  • If a count is not 5, a printf line is missing or has too much; check the file with cat and run the command again.
  • If you see a literal n instead of a newline, check the single quotes.

Run three sed commands. The files stay unchanged, only the output differs. Paste the output.

cd ~/lab

sed -n '2,3p' pets.txt
sed '1d' employees.csv

sed -i with a backup

Change the port in server.conf with a backup and show the difference. Paste the output.

cd ~/lab
# GNU sed (Ubuntu/Rocky/Alma); -i.bak makes a backup
sed -i.bak 's/8080/9090/' server.conf
grep port server.conf
diff server.conf.bak server.conf

My output looks different
  • On macOS/BSD -i.bak works too; without a suffix you need sed -i '' ....
  • If the diff output is empty nothing changed; check the spelling of 8080.
  • To undo: cp server.conf.bak server.conf.

awk: column, condition, sum

Run three awk commands on employees.csv: two columns, salaries over 5000, total and average.

cd ~/lab
awk -F, 'NR>1 {print $1, $3}' employees.csv
awk -F, 'NR>1 && $3 > 5000 {print $1}' employees.csv
awk -F, 'NR>1 {s+=$3} END {printf "total=%d avg=%.1f\n", s, s/(NR-1)}' employees.csv

Expected output example

anna 5200
ben 4100
cara 6100
dan 3900
anna
cara
total=19300 avg=4825.0
My output looks different
  • Depending on the locale the decimal separator may be 4825,0.
  • If you see total=0, -F, is missing or the shell expanded $3; put the program in single quotes.

Log analysis: counting

Count the status codes in access.log with an awk array, find the 404 line with sed and paste the output. Optionally count running processes per user.

cd ~/lab
awk '{c[$2]++} END {for (k in c) print k, c[k]}' access.log | sort
sed -n '/404/p' access.log
ps aux | awk 'NR>1 {print $1}' | sort | uniq -c | sort -rn | head -3

Expected output example

200 3
404 1
500 1
10.0.0.2 404
    120 root
     35 student
      4 www-data
My output looks different
  • The numbers and users of the last command depend on your system; what matters is the count user format on each line.
  • The order of for (k in c) is undefined, which is why we added sort.

Self-test

What does sed 's/a/b/' file do without the g flag?

Without g only the first match per line is replaced; and without -i the file is not changed at all.

What is the safest way to edit a configuration file in place?

-i.bak keeps the original as file.bak; -i alone cannot be undone.

What does awk -F, '{print $NF}' employees.csv print?

NF is the field count, $NF is the value of the last field.

What is NR>1 for in awk -F, 'NR>1 {s+=$3} END {print s}'?

NR is the line number; NR>1 runs the action on every line except the header.

Summary

  • sed 's/old/new/g' substitutes; -n + p selects, d deletes. Without -i the file never changes.
  • sed -i is permanent: use -i.bak for a backup. On macOS you need -i ''.
  • awk splits lines into fields: $1, $NF, -F,; calculate with NR, NF, BEGIN, END.
  • With the associative array c[$2]++ you count values in logs; sort the output with sort.
  • Always put programs in single quotes and check the result on screen first.

Key terms

sed
Stream editor that processes text line by line.
awk
Text-processing language that splits lines into fields and supports conditions, calculations and reports.
field
A part of a line that awk splits off at the separator: $1, $2, … $NF.
address
A number, range or regex that selects which lines a sed command applies to.
in-place editing
With sed -i the result is written into the file itself instead of the screen.
associative array
An awk array holding key-value pairs; typical for counters.
regex
A regular expression describing a text pattern; sed and awk use it for matching.
