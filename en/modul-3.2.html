3.2 Redirection and Pipes

A pipe connects the output of one command to the input of the next. Small tools combined this way solve big problems.

What will you learn in this module?

  • You chain commands with | into pipelines.
  • You count, sort and deduplicate with wc, sort and uniq.
  • You combine pipes and redirection, and split a stream with tee.

The pipe: command | command

| connects stdout of the left command to stdin of the right one. Nothing is written to disk in between. Each tool does one thing; the pipe combines them.

Only stdout travels through a pipe. Error messages (stderr) still go to the screen unless you add 2>&1 before the pipe.

wc -l

What is it for?
Counts lines.
Where is it used?
At the end of a pipeline to count results.
Why does it matter?
Answers 'how many?'.
cat logs/app.log | wc -l

grep

What is it for?
Keeps only lines that match a pattern.
Where is it used?
To filter logs and lists.
Why does it matter?
Reduces a big stream to the interesting lines.
grep ERROR logs/app.log | wc -l

head / tail

What is it for?
Shows the first / last lines.
Where is it used?
To see the top or bottom of a result.
Why does it matter?
Keeps output short.
sort -n data/nums.txt | tail -n 1
💡 Tip

Build a pipeline step by step: run the first command, check the output, then add the next |.

sort, uniq and tee

uniq only collapses adjacent duplicate lines, so you almost always run sort first. uniq -c prefixes each line with its count; sort -rn then ranks them by that number.

sort compares text by default, so 10 comes before 9. Use sort -n for numbers. tee file writes the stream to a file and passes it on, like a T-junction.

sort

What is it for?
Sorts lines; -n numeric, -r reverse, -u unique.
Where is it used?
Before uniq or to rank values.
Why does it matter?
Brings similar lines together.
sort data/fruits.txt

uniq -c

What is it for?
Collapses adjacent duplicates and counts them.
Where is it used?
To build frequency tables.
Why does it matter?
Shows how often each line occurs.
sort data/fruits.txt | uniq -c

tee

What is it for?
Saves the stream to a file and also passes it on.
Where is it used?
To keep an intermediate result of a pipeline.
Why does it matter?
You see and store the data in one go.
grep ERROR logs/app.log | tee all_errors.txt | wc -l
💡 Tip

The classic ranking: sort | uniq -c | sort -rn.

⚠️ Warning

uniq without sort leaves duplicates that are not next to each other.

Do it on your own VM

The real practice happens on real Linux: run the commands in your own virtual machine (VirtualBox, UTM or WSL) and compare the output.

On your VM these pipelines only read; the only files written are ones you create in your home directory.

Count with a pipe

Count how many entries /etc has and paste the number.

ls /etc | wc -l

Expected output example

187
My output looks different
  • The number depends on your system; any number is fine.

Extract and sort users

Take the first field of /etc/passwd, sort it and show the first five names.

cut -d: -f1 /etc/passwd | sort | head -n 5

Expected output example

_apt
backup
bin
daemon
games
My output looks different
  • Names differ per distribution; only the alphabetical order matters. Use | grep root to check that root exists.

Frequency table

Count which login shells are used in /etc/passwd and rank them.

cut -d: -f7 /etc/passwd | sort | uniq -c | sort -rn

Expected output example

     24 /usr/sbin/nologin
      3 /bin/bash
      1 /bin/sync
My output looks different
  • Counts and shells vary per system.
  • If you see only one line, check that sort comes before uniq -c.

Keep a copy with tee

Save a listing with tee while counting it; check the file. If it worked press "Done".

ls /etc | tee ~/etc_list.txt | wc -l
head -n 3 ~/etc_list.txt
My output looks different
  • If etc_list.txt is empty, check that you wrote ~/etc_list.txt after tee.

Self-test

What does the pipe | connect?

The pipe feeds the left command's stdout into the right command's stdin.

Why is sort used before uniq?

Sorting makes identical lines adjacent.

What does tee out.txt do in a pipeline?

tee splits the stream like a T-piece.

Which command prints the largest number of a file with one number per line?

sort -n ranks numerically; the last line is the largest.

Summary

  • cmd1 | cmd2 passes stdout of cmd1 as stdin to cmd2.
  • sort | uniq -c | sort -rn builds a frequency ranking.
  • sort -n sorts numerically; plain sort sorts as text.
  • tee stores a stream in a file while passing it on.

Key terms

pipe
Connects the output of one command to the input of another.
pipeline
A chain of commands joined by pipes.
filter
A command that reads stdin and writes a changed stream to stdout.
tee
Writes a stream to a file and to stdout.
