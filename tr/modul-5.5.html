5.5 Paket Yönetimi

Dağıtımına uygun paket yöneticisiyle yazılım ara, kur, güncelle ve kaldır; paket depoları ile kurulu paket veritabanını ayırt et.

Bu modülde neler öğreneceksin?

  • Debian ailesinde apt/dpkg, RHEL ailesinde dnf/rpm kullanıldığını bilirsin.
  • Paket arama, bilgi alma, kurulum, güncelleme ve kaldırma adımlarını uygularsın.
  • Kurulum öncesi değişiklikleri inceler ve kritik paketleri korursun.

Dağıtımlar ve paket araçları

Paket yöneticileri yazılımı imzalı depolardan indirir, bağımlılıkları çözer ve kurulu paket veritabanını günceller. Ubuntu ve Debian'da üst düzey araç apt, düşük düzey sorgu aracı dpkg; Rocky, Alma ve Fedora'da dnf ve rpm kullanılır.

Aynı yazılımın paket adı dağıtımlar arasında değişebilir: RHEL ailesinde Apache HTTP Server genellikle httpd, Debian ailesinde apache2 adıyla bulunur. Önce hangi dağıtımda olduğunu ve doğru paket adını öğren.

cat /etc/os-release

Ne işe yarar?
Dağıtım adını, sürümünü ve kimliğini gösterir.
Nerede kullanılır?
Paket komutu veya servis adı seçmeden önce.
Neden önemli?
Sistemin Debian mı RHEL ailesi mi olduğunu doğrular.
cat /etc/os-release

apt search / dnf search

Ne işe yarar?
Yapılandırılmış depolarda ada veya açıklamaya göre paket arar.
Nerede kullanılır?
Paket adından emin olmadığında.
Neden önemli?
Yanlış paketi kurma ihtimalini azaltır.
dnf search nginx
💡 İpucu

apt ve dnf komutlarını sistem ailesine göre seç; aynı komutun iki ailede de bulunduğunu varsayma.

Arama, kurulum ve güncelleme

Kurulumdan önce paketin açıklamasını ve hangi depodan geldiğini incele. apt update Debian ailesinde paket listelerini yeniler; paketleri tek başına yükseltmez. dnf check-update güncelleme olup olmadığını denetler.

Paket kurma ve sistem güncelleme yönetici izni ister. Onay ekranında kurulacak, kaldırılacak ve güncellenecek paketleri oku; beklenmeyen kritik değişiklik varsa işlemi iptal et.

sudo apt install package / sudo dnf install package

Ne işe yarar?
Depodan paketi ve gerekli bağımlılıklarını kurar.
Nerede kullanılır?
Paket adını ve kaynağını doğruladıktan sonra.
Neden önemli?
Dosyaları elle indirip yerleştirmek yerine paket veritabanını tutarlı günceller.
sudo dnf install cowsay

sudo apt update / sudo dnf check-update

Ne işe yarar?
Depo paket bilgilerini yeniler veya güncelleme olup olmadığını denetler.
Nerede kullanılır?
Debian tabanlı sistemde kurulumdan önce veya güncelleme kontrolünde.
Neden önemli?
Paket yöneticisinin güncel depo bilgisini kullanmasını sağlar.
sudo apt update
💡 İpucu

apt update paket listelerini yeniler; kurulu paketleri yükseltmek için ayrıca apt upgrade gerekir.

Kaldırma ve paket doğrulama

apt remove ve dnf remove paketi kaldırırken bağımlılıkları da etkileyebilir. apt purge ayrıca paket yapılandırmasını kaldırır; autoremove artık gerekmeyen bağımlılıkları bulur. Önerilen kaldırma listesini dikkatle incele.

dpkg -l veya rpm -qa kurulu paketleri listeler. Bu düşük düzey araçlar paketleri kurmak için değil, sorgulamak için uygundur; kurulum ve kaldırmada apt veya dnf kullan.

sudo apt remove / sudo dnf remove

Ne işe yarar?
Paket yöneticisi üzerinden paketi kaldırır.
Nerede kullanılır?
Deneme paketi artık gerekmediğinde.
Neden önemli?
Paket veritabanını ve bağımlılıkları kontrollü biçimde günceller.
sudo apt remove cowsay

dpkg -l / rpm -qa

Ne işe yarar?
Kurulu paketlerin listesini sorgular.
Nerede kullanılır?
Paketin kurulu olup olmadığını doğrularken.
Neden önemli?
Sistemdeki kurulum durumunu paket veritabanından gösterir.
rpm -qa | grep cowsay
⚠️ Dikkat

Paket eklemek veya kaldırmak sistemi değiştirir. Yalnızca kendi VM'inde dene; kernel, systemd, SSH ve ağ paketlerini kaldırma. Onay listesini oku.

Kendi VM'inde yap

Asıl uygulama gerçek Linux'ta yapılır: kendi sanal makinende (VirtualBox, UTM veya WSL) komutları çalıştır, çıktıyı karşılaştır.

Paket kurma ve kaldırma sistemde değişiklik yapar. Yalnızca kendi test VM'inde çalış; üretim sisteminde paket işlemi yapma ve onay ekranlarını mutlaka oku.

Dağıtımı tanı

Dağıtım kimliğini ve sistemde bulunan paket aracını kontrol et.

cat /etc/os-release
command -v apt
dnf --version

Beklenen çıktı örneği

ID= satırı dağıtımı gösterir; kullandığın ailede apt veya dnf bulunur.
Çıktım farklı çıktı
  • Her iki paket aracının da bulunması gerekmez; dağıtımına uygun olanı kullan.
  • ID veya ID_LIKE alanı dağıtım ailesini belirlemeye yardımcı olur.

Paketi kurmadan araştır

Önce cowsay paketinin bilgisini görüntüle. Yalnızca dağıtımına uygun komutu çalıştır.

apt-cache policy cowsay

Beklenen çıktı örneği

Candidate veya paket sürümü
dnf info cowsay

Beklenen çıktı örneği

Available Packages veya paket bilgisi
Çıktım farklı çıktı
  • Debian/Ubuntu'da apt-cache; Rocky/Alma/Fedora'da dnf kullan.
  • Paket bulunamazsa depo listesi güncel olmayabilir veya etkin depo paketi içermeyebilir.

Test paketini kur

Yalnızca kendi test VM'inde, dağıtımına uygun komutla küçük cowsay paketini kur. Onay ekranındaki değişiklikleri incele.

sudo apt install cowsay

Beklenen çıktı örneği

Setting up cowsay veya kurulum tamamlandı
sudo dnf install cowsay

Beklenen çıktı örneği

Complete! veya Installed: cowsay
Çıktım farklı çıktı
  • Yalnızca bir blok çalıştır: Debian/Ubuntu için apt, RHEL ailesi için dnf.
  • Paket bulunmuyorsa işlemi zorlamadan önce doğru depo ve paket adını araştır.

Test paketini kaldır

Kurulumdan sonra aynı paket yöneticisiyle cowsay paketini kaldır ve sonucu doğrula. Önerilen kaldırılacak paketleri onaylamadan önce incele.

sudo apt remove cowsay

Beklenen çıktı örneği

Removing cowsay veya cowsay kaldırıldı
sudo dnf remove cowsay

Beklenen çıktı örneği

Removing: cowsay veya Complete!
Çıktım farklı çıktı
  • Yalnızca paketi kurduğun dağıtım ailesinin komutunu çalıştır.
  • Beklenmeyen önemli paketler listelenirse onaylama; n ile iptal et.

Hızlı alıştırmalar (simülatör)

İsteğe bağlı: VM'e geçmeden önce ısınmak veya VM'in yokken denemek için tarayıcıdaki sanal terminali kullan. Görevler otomatik doğrulanır.

Görevler ısınmadan ticket'a doğru zorlaşır. Rozetler zorluğu gösterir.

Hata ayıkla

  1. Hata ayıklaOrta

    Çözüm

Mini proje

  1. Mini projeOrta

    Çözüm

    Çözüm

Öz test

Ubuntu ve Debian'da yaygın üst düzey paket aracı hangisidir?

apt Debian ailesinde depoları ve paket kurulumunu yönetir.

RHEL ailesinde Apache HTTP Server paketi genellikle hangi adla geçer?

RHEL ailesinde paket adı genellikle httpd; Debian ailesinde apache2'dir.

apt update ne yapar?

apt update yerel depo indekslerini yeniler; kurulu paketleri yükseltmek için apt upgrade gerekir.

Kurulum onay ekranında ne yapmalısın?

Bağımlılık çözümü başka paketleri de değiştirebilir; işlemden önce listeyi gözden geçir.

Özet

  • Ubuntu/Debian: apt/dpkg; Rocky/Alma/Fedora: dnf/rpm. Önce dağıtımını ve paket adını doğrula.
  • apt update depo listelerini yeniler; kurulum ve yükseltme ayrı işlemlerdir.
  • Paket kaldırma ve autoremove öncesinde önerilen değişiklikleri incele; kritik sistem paketlerini koru.

Terimler

repository
Dağıtımın paketleri ve paket bilgilerini yayımladığı yazılım deposu.
dependency
Bir paketin çalışması veya kurulması için gereken başka paket.
package manager
Paketleri ve bağımlılıkları kuran, güncelleyen, kaldıran araç.
