2.5 Dosya bilgisi

file, stat, ls -l, ln -s, readlink ve realpath ile bir dosyanın gerçek türünü, boyutunu, zamanını ve link hedefini oku.

Bu modülde neler öğreneceksin?

  • Linux'ta uzantının sadece bir isim olduğunu, gerçek türü file ile öğrendiğini bilirsin.
  • stat ve ls -l ile boyut, izin, sahip ve zaman bilgisini okursun.
  • Sembolik linkleri kurar, hedeflerini ls -l, readlink ve realpath ile bulursun.

Gerçek tür: file

Windows'ta uzantıya bakarak türü anlarsın. Linux'ta .jpg sadece isimdir; içerik başka bir şey olabilir. file uzantıya değil, içeriğin ilk baytlarına bakar.

Bu, indirdiğin bir dosyanın gerçekten ne olduğunu kontrol etmek için işe yarar: resim.jpg adlı bir dosya aslında çalıştırılabilir program olabilir.

file

Ne işe yarar?
Dosyanın gerçek türünü içeriğinden söyler.
Nerede kullanılır?
İndirilen veya şüpheli dosyalarda.
Neden önemli?
Yanlış uzantıyı ve gizlenmiş dosyayı ortaya çıkarır.
file /etc/hostname

file -i

Ne işe yarar?
Türü MIME biçiminde yazar (örneğin text/plain).
Nerede kullanılır?
Betiklerde ve web sunucusu ayarlarında.
Neden önemli?
Makinenin okuyabileceği kısa bir tür verir.
file -i /etc/hostname
💡 İpucu

Çıktıda ASCII text metin, ELF çalıştırılabilir program, directory klasör demektir.

Ayrıntılar: stat ve ls -l

ls -l bir satırda tür, izin, sahip, boyut ve tarih gösterir. stat daha fazlasını verir: inode, bağ sayısı ve üç zaman damgası.

Zamanlar: Access son okuma, Modify içeriğin son değişimi, Change izin veya sahip gibi metadata'nın son değişimi. İlk karakter türü söyler: - dosya, d klasör, l sembolik link.

stat

Ne işe yarar?
Bir dosyanın tüm teknik bilgisini gösterir.
Nerede kullanılır?
Tam boyut, izin ve zaman gerektiğinde.
Neden önemli?
ls -lden daha ayrıntılıdır.
stat ~/info/data.txt

ls -l

Ne işe yarar?
Uzun biçimli liste verir.
Nerede kullanılır?
Klasör içeriğine hızlı bakarken.
Neden önemli?
Tür, izin, sahip, boyut ve tarih tek satırda.
ls -l ~/info

ls -lh

Ne işe yarar?
Boyutları KB/MB gibi okunur yazar.
Nerede kullanılır?
Büyük dosyalarda.
Neden önemli?
Bayt sayısı yerine anlaşılır boyut.
ls -lh ~/info

ls -ld

Ne işe yarar?
Klasörün kendisini listeler, içeriğini değil.
Nerede kullanılır?
Bir klasörün iznine bakarken.
Neden önemli?
İçini açmadan klasör bilgisi verir.
ls -ld ~/info
💡 İpucu

ls -lh boyutu yuvarlar; tam bayt için stat veya wc -c kullan.

Sembolik linkler ve gerçek yol

Sembolik link (symlink) başka bir yolu gösteren küçük bir dosyadır. ls -l bunu link.txt -> data.txt diye gösterir. Hedef yoksa link kırık olur: link vardır ama içine bakınca hata alırsın.

Linki silmek hedefi silmez; rm link.txt yalnızca linki kaldırır. readlink bir adım hedefi, realpath tüm linkleri çözülmüş mutlak yolu verir.

ln -s

Ne işe yarar?
Sembolik link oluşturur: önce hedef, sonra link adı.
Nerede kullanılır?
Kısayol veya sürüm işaretçisi için.
Neden önemli?
Dosyayı kopyalamadan ikinci bir adla erişirsin.
ln -s data.txt ~/info/link.txt

readlink

Ne işe yarar?
Linkin gösterdiği hedefi yazar.
Nerede kullanılır?
Linkin nereye gittiğini bulurken.
Neden önemli?
Betiklerde hedefi temiz alırsın.
readlink ~/info/link.txt

realpath

Ne işe yarar?
Linkleri çözülmüş tam mutlak yolu verir.
Nerede kullanılır?
Göreli yolu veya link zincirini netleştirirken.
Neden önemli?
Dosyanın diskteki gerçek konumunu gösterir.
realpath ~/info/link.txt
⚠️ Dikkat

Hedef yolu link klasörüne göreli yazılır. ln -s data.txt ~/info/link.txt doğru çalışır; farklı klasörde ln -s data.txt ~/link.txt kırık link üretir.

İsim ve boyut: basename, dirname, wc

basename yolun son parçasını, dirname klasör kısmını verir. Betiklerde yolu parçalamak için sık kullanılır.

Boyutu bayt olarak wc -c, satır sayısını wc -l söyler.

basename

Ne işe yarar?
Yolun son bileşenini (dosya adı) verir.
Nerede kullanılır?
Betiklerde dosya adı gerektiğinde.
Neden önemli?
Yolu elle kesmeden adı alırsın.
basename ~/info/data.txt

dirname

Ne işe yarar?
Yolun klasör kısmını verir.
Nerede kullanılır?
Dosyanın bulunduğu klasörü bulurken.
Neden önemli?
Dosya adını atıp klasörü alırsın.
dirname ~/info/data.txt

wc -c

Ne işe yarar?
Dosyanın bayt sayısını verir.
Nerede kullanılır?
Tam boyut gerektiğinde.
Neden önemli?
Yuvarlama olmadan kesin boyut.
wc -c ~/info/data.txt

Kendi VM'inde yap

Asıl uygulama gerçek Linux'ta yapılır: kendi sanal makinende (VirtualBox, UTM veya WSL) komutları çalıştır, çıktıyı karşılaştır.

Kendi VM'inde dene. Burada yıkıcı komut yok; yalnızca home dizininde küçük deneme dosyaları açarsın.

Gerçek türü öğren

Bir metin dosyası, bir program ve bir klasör için file çalıştır, çıktıyı yapıştır.

file /etc/hostname /usr/bin/ls /etc

Beklenen çıktı örneği

/etc/hostname: ASCII text
/usr/bin/ls:  ELF 64-bit LSB pie executable, x86-64, ...
/etc:         directory
Çıktım farklı çıktı
  • ls konumu dağıtıma göre değişir; which ls ile bul.
  • file yoksa Ubuntu'da sudo apt install file, Rocky/Alma'da sudo dnf install file kur.

Yalan söyleyen uzantı

Metin içeren bir dosyaya .jpg adı ver ve file ne diyor bak.

echo hello > ~/fake.jpg
file ~/fake.jpg

Beklenen çıktı örneği

/home/student/fake.jpg: ASCII text
Çıktım farklı çıktı
  • Yol sende /home/alice/fake.jpg olabilir; önemli olan text kelimesidir.

stat ile ayrıntı

stat çıktısında Size, Modify ve Change satırlarını bul.

stat ~/fake.jpg

Beklenen çıktı örneği

  File: /home/student/fake.jpg
  Size: 6   Blocks: 8   regular file
Access: (0644/-rw-r--r--) ...
Modify: 2026-01-01 10:00:00 ...
Çıktım farklı çıktı
  • Çıktın Türkçe ise Size yerine Boyut görebilirsin; LANG=C stat ~/fake.jpg İngilizce verir.
  • Birth satırı bazı dosya sistemlerinde - olur.

Link ve gerçek yol

Sembolik link kur, ls -l, readlink ve realpath ile hedefi bul.

ln -s fake.jpg ~/pic_link
ls -l ~/pic_link
readlink ~/pic_link
realpath ~/pic_link

Beklenen çıktı örneği

lrwxrwxrwx 1 student student 8 ... /home/student/pic_link -> fake.jpg
fake.jpg
/home/student/fake.jpg
Çıktım farklı çıktı
  • ls -l çıktısında -> yoksa ln -s sırasını (hedef, sonra link adı) kontrol et.
  • realpath yoksa readlink -f ~/pic_link aynı işi görür.

Temizlik

Denemelerde açtığın dosyaları sil. Hata yoksa "Yaptım"a bas.

ls -l ~/fake.jpg ~/pic_link
rm ~/pic_link ~/fake.jpg
Çıktım farklı çıktı
  • rm önce linki kaldırır; sonra hedef dosyayı. Sırayı ters yaparsan link kırık kalır, ama zararsızdır.

Öz test

file resim.jpg bir dosyanın türünü neye göre söyler?

Linux'ta uzantı sadece isimdir; file içeriğe bakar.

stat çıktısındaki Modify zamanı neyi gösterir?

Modify içeriğin, Change metadata'nın, Access son okumanın zamanıdır.

rm link.txt (sembolik link) çalıştırılırsa ne olur?

Link kendi başına bir kayıttır; silmek hedefe dokunmaz.

Linklerin tümü çözülmüş mutlak yolu hangi komut verir?

realpath göreli yolu ve link zincirini çözüp gerçek mutlak yolu yazar.

Özet

  • Uzantı sadece isimdir; gerçek tür için file kullan.
  • ls -l hızlı özet, stat ayrıntı verir; Modify içerik, Change metadata zamanıdır.
  • ln -s hedef link sembolik link kurar; ls -lde -> görünür.
  • readlink bir adım hedefi, realpath tam mutlak yolu verir; rm link hedefi silmez.

Terimler

symlink
Başka bir yolu gösteren özel dosya.
inode
Dosya sisteminde dosyanın metadata kaydı.
dangling link
Hedefi olmayan kırık sembolik link.
MIME type
İçerik türünü gösteren etiket, örneğin text/plain.
