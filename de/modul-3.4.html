3.4 Suchen: grep und find

grep durchsucht Zeilen innerhalb von Dateien, find sucht Dateien und Verzeichnisse in einem Verzeichnisbaum. Kombiniere beide Werkzeuge, um Logs und Projektdateien schnell zu untersuchen.

Was lernst du in diesem Modul?

  • Dateiinhalte mit grep durchsuchen.
  • Die Optionen -i, -n, -v und -c erklären.
  • Dateien mit find nach Name und Typ finden.
  • Suchergebnisse mit Pipes und Umleitungen weiterverwenden.

Dateiinhalte mit grep durchsuchen

grep MUSTER DATEI gibt passende Zeilen aus. Das Muster kann einfacher Text oder ein regulärer Ausdruck sein. Mit -i wird die Groß-/Kleinschreibung ignoriert, -n zeigt Zeilennummern, -v wählt nicht passende Zeilen und -c zählt Trefferzeilen.

grep kann auch Text aus einer Pipe lesen, wenn kein Dateiname angegeben ist. So filterst du lange Ausgaben mit Befehl | grep Muster.

grep -n

Wozu dient es?
Zeigt zu passenden Zeilen auch die Zeilennummer.
Wo wird es verwendet?
Wenn du eine Fundstelle in einer Datei lokalisieren möchtest.
Warum ist es wichtig?
So kannst du das Ergebnis leichter finden und prüfen.
grep -n ERROR logs/app.log

grep -i

Wozu dient es?
Ignoriert Unterschiede zwischen Groß- und Kleinbuchstaben.
Wo wird es verwendet?
Wenn Logmeldungen unterschiedlich geschrieben sind.
Warum ist es wichtig?
error, Error und ERROR werden gefunden.
grep -i error logs/app.log

grep -v

Wozu dient es?
Zeigt Zeilen, die nicht zum Muster passen.
Wo wird es verwendet?
Wenn unerwünschte Zeilen ausgeschlossen werden sollen.
Warum ist es wichtig?
Filtert die Umkehrung einer Übereinstimmung.
grep -v INFO logs/app.log

grep -c

Wozu dient es?
Gibt die Anzahl der passenden Zeilen aus.
Wo wird es verwendet?
Wenn du Ereignisse in einem Log zählen möchtest.
Warum ist es wichtig?
Liefert eine Summe, ohne jede Zeile auszugeben.
grep -c ERROR logs/app.log
💡 Tipp

Gib Muster und Dateiname als getrennte Argumente an. Setze Suchtext mit Sonderzeichen in Anführungszeichen.

Das Dateisystem mit find durchsuchen

find START ... durchsucht den Verzeichnisbaum ab dem angegebenen Pfad. -name wählt ein Namensmuster, -type f reguläre Dateien und -type d Verzeichnisse. Setze Dateimuster in Anführungszeichen, damit die Shell * nicht vor find erweitert.

find kann nach mehr als dem Namen suchen und seine Ausgabe an ein anderes Kommando weitergeben. locate durchsucht einen vorbereiteten Dateinamenindex; das geht schnell, aber neue Dateien sind möglicherweise noch nicht aufgenommen. Ein gezielter Startpfad vermeidet unnötige Systemverzeichnisse.

find . -name

Wozu dient es?
Sucht in einem Verzeichnisbaum nach Namen.
Wo wird es verwendet?
Wenn der Name oder die Erweiterung einer Projektdatei bekannt ist.
Warum ist es wichtig?
Unterverzeichnisse werden ebenfalls durchsucht.
find project -name "*.conf"

find . -type f

Wozu dient es?
Wählt nur reguläre Dateien aus.
Wo wird es verwendet?
Wenn Dateien von Verzeichnissen unterschieden werden sollen.
Warum ist es wichtig?
Begrenzt die Ergebnisse auf einen Objekttyp.
find project -type f -name "*.txt"

find . -type d

Wozu dient es?
Wählt nur Verzeichnisse aus.
Wo wird es verwendet?
Wenn du Ordner in einem Projekt finden möchtest.
Warum ist es wichtig?
Verhindert, dass Ordnernamen mit Dateinamen verwechselt werden.
find project -type d

locate

Wozu dient es?
Durchsucht schnell einen indizierten Dateinamensbestand.
Wo wird es verwendet?
Wenn du den Pfad einer bekannten Datei systemweit finden möchtest.
Warum ist es wichtig?
Bei aktuellem Index ist es schnell; neue Dateien sind möglicherweise noch nicht enthalten.
locate sshd_config
⚠️ Achtung

find / kann das ganze System durchsuchen und Berechtigungswarnungen ausgeben. Beginne mit einem engen Pfad wie deinem Projekt- oder Home-Verzeichnis.

Suchen kombinieren und Ergebnisse speichern

grep und find beantworten unterschiedliche Fragen: grep findet Text in Dateien, find ermittelt Dateien anhand ihres Namens und Pfads. Speichere Ergebnisse mit > oder leite sie mit | an einen weiteren Filter weiter.

Prüfe Suchergebnisse, bevor du wichtige Dateien änderst. Die Befehle in diesem Modul suchen und lesen; eine Umleitung erstellt nur in deinem Arbeitsverzeichnis einen Bericht.

grep -r

Wozu dient es?
Durchsucht Dateien eines Verzeichnisses rekursiv.
Wo wird es verwendet?
Wenn du wissen möchtest, wo ein Begriff oder eine Einstellung im Projekt vorkommt.
Warum ist es wichtig?
Du musst Dateien nicht einzeln öffnen.
grep -r TODO project

find . -type f -name "*.txt" > list.txt

Wozu dient es?
Schreibt Pfade passender Textdateien in eine Liste.
Wo wird es verwendet?
Wenn du Suchergebnisse später prüfen möchtest.
Warum ist es wichtig?
Der Bericht bleibt wiederverwendbar erhalten.
find project -type f -name "*.txt" > text_files.txt
💡 Tipp

Führe die Suche zuerst aus und prüfe die Ausgabe. Leite sie bei Bedarf danach in einen Bericht um.

Mach es in deiner VM

Die eigentliche Praxis findet auf echtem Linux statt: Führe die Befehle in deiner eigenen virtuellen Maschine (VirtualBox, UTM oder WSL) aus und vergleiche die Ausgabe.

Lies vorhandene Texte und Pfade auf deiner VM. Diese Befehle ändern keine Systemdateien; lege Berichte in deinem Home-Verzeichnis ab.

Ein Log durchsuchen

Suche ohne Beachtung der Groß-/Kleinschreibung nach error in einem Systemlog und füge eine Trefferzeile ein.

grep -i error /var/log/messages | head -n 3

Beispiel der erwarteten Ausgabe

error
Meine Ausgabe sieht anders aus
  • Falls dieses Log nicht vorhanden ist, wähle ein Log deiner Distribution oder erstelle ~/lab/app.log mit Beispielzeilen.

Zeilennummern anzeigen

Finde die root-Zeile in /etc/passwd mit Zeilennummer.

grep -n '^root:' /etc/passwd

Beispiel der erwarteten Ausgabe

1:root:
Meine Ausgabe sieht anders aus
  • Die Zeilennummer kann abweichen; die Ausgabe sollte root und davor eine Nummer enthalten.

Nach Dateinamen suchen

Finde unter /etc die Datei mit dem Namen hostname.

find /etc -type f -name hostname

Beispiel der erwarteten Ausgabe

/etc/hostname
Meine Ausgabe sieht anders aus
  • Die Ausgabe sollte den vollständigen Pfad enthalten. find erhält Startverzeichnis und Name als getrennte Argumente.

Ergebnisse sicher speichern

Erstelle lab in deinem Home-Verzeichnis, lege dort einen Bericht mit .txt-Dateien an und prüfe ihn.

mkdir -p ~/lab && cd ~/lab && touch notes.txt readme.txt && find . -type f -name '*.txt' > files.txt && cat files.txt
Meine Ausgabe sieht anders aus
  • Ist der Bericht leer, prüfe, ob cd ~/lab erfolgreich war und die Dateinamen stimmen. Durchsuche nicht das ganze System.

Selbsttest

Was macht grep -i error file?

-i macht die Suche unabhängig von Groß- und Kleinschreibung.

Was ergänzt grep -n in der Ausgabe?

-n zeigt die Zeilennummer jedes Treffers.

Wonach sucht find project -type f -name '*.txt'?

Der Startpfad ist project, der Typ ist reguläre Datei und das Namensmuster endet auf .txt.

Welcher Befehl durchsucht Dateiinhalte rekursiv nach TODO?

grep -r durchsucht Dateiinhalte rekursiv in einem Verzeichnisbaum.

Zusammenfassung

  • grep durchsucht Dateiinhalte; find findet Dateien und Verzeichnisse in einem Baum.
  • grep -i ignoriert Groß-/Kleinschreibung, -n zeigt Zeilennummern, -v kehrt Treffer um und -c zählt sie.
  • find -name wählt ein Namensmuster, -type f reguläre Dateien und -type d Verzeichnisse.
  • Setze Dateimuster in Anführungszeichen, damit die Shell * nicht vor der Suche erweitert.
  • Beginne in einem engen Verzeichnis statt unnötig einen großen Baum zu durchsuchen.

Fachbegriffe

grep
Ein Suchwerkzeug, das passende Zeilen in Textdateien findet.
find
Ein Dateisuchwerkzeug, das an einem Verzeichnis beginnt und den Baum absteigt.
regulärer Ausdruck
Eine Mustersyntax zum Abgleichen von Text.
rekursive Suche
Eine Suche, die auch Unterverzeichnisse besucht.
