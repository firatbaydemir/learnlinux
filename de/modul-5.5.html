5.5 Paketverwaltung

Suche, installiere, aktualisiere und entferne Software mit dem Paketmanager deiner Distribution; unterscheide Paketquellen und installierte Paketdatenbank.

Was lernst du in diesem Modul?

  • Du weißt, dass Debian-Systeme apt/dpkg und RHEL-Systeme dnf/rpm verwenden.
  • Du führst Suche, Informationsabfrage, Installation, Aktualisierung und Entfernung aus.
  • Du prüfst Änderungen vor der Installation und schützt kritische Pakete.

Distributionen und Paketwerkzeuge

Paketmanager laden Software aus signierten Repositories, lösen Abhängigkeiten auf und aktualisieren die installierte Paketdatenbank. Ubuntu und Debian verwenden apt als übergeordnetes Werkzeug und dpkg für Abfragen auf niedrigerer Ebene; Rocky, Alma und Fedora verwenden dnf und rpm.

Der Paketname derselben Software kann je nach Distribution abweichen: Apache HTTP Server heißt in der RHEL-Familie meist httpd, in der Debian-Familie apache2. Finde zuerst die Distribution und den richtigen Paketnamen heraus.

cat /etc/os-release

Wozu dient es?
Zeigt Name, Version und Kennung der Distribution.
Wo wird es verwendet?
Bevor du einen Paketbefehl oder Dienstnamen wählst.
Warum ist es wichtig?
Damit bestätigst du, ob das System zur Debian- oder RHEL-Familie gehört.
cat /etc/os-release

apt search / dnf search

Wozu dient es?
Sucht in konfigurierten Repositories nach Namen oder Beschreibung.
Wo wird es verwendet?
Wenn du den Paketnamen nicht kennst.
Warum ist es wichtig?
Das senkt das Risiko, das falsche Paket zu installieren.
dnf search nginx
💡 Tipp

Wähle apt oder dnf passend zur Systemfamilie; gehe nicht davon aus, dass derselbe Befehl überall verfügbar ist.

Suche, Installation und Aktualisierung

Prüfe vor der Installation Beschreibung und Herkunft des Pakets. apt update aktualisiert in der Debian-Familie die Paketlisten, führt aber nicht selbst ein Paketupgrade aus. dnf check-update prüft, ob Aktualisierungen verfügbar sind.

Die Installation von Paketen und Systemupdates erfordert Administratorrechte. Lies im Bestätigungsdialog die Pakete, die installiert, entfernt oder aktualisiert werden sollen. Brich ab, wenn kritische unerwartete Änderungen aufgeführt sind.

sudo apt install package / sudo dnf install package

Wozu dient es?
Installiert ein Paket aus dem Repository samt benötigten Abhängigkeiten.
Wo wird es verwendet?
Nachdem Paketname und Quelle geprüft wurden.
Warum ist es wichtig?
Die Paketdatenbank bleibt konsistent, statt Dateien manuell herunterzuladen und abzulegen.
sudo dnf install cowsay

sudo apt update / sudo dnf check-update

Wozu dient es?
Aktualisiert Paketinformationen oder prüft verfügbare Updates.
Wo wird es verwendet?
Vor Installationen auf Debian-Systemen oder bei der Updateprüfung.
Warum ist es wichtig?
Der Paketmanager nutzt aktuelle Repositoryinformationen.
sudo apt update
💡 Tipp

apt update aktualisiert die Paketlisten; installierte Pakete aktualisierst du separat mit apt upgrade.

Entfernen und Pakete prüfen

apt remove und dnf remove können beim Entfernen eines Pakets auch Abhängigkeiten betreffen. apt purge entfernt zusätzlich die Paketkonfiguration; autoremove findet nicht mehr benötigte Abhängigkeiten. Prüfe die vorgeschlagene Entfernung sorgfältig.

dpkg -l oder rpm -qa listet installierte Pakete auf. Diese Werkzeuge auf niedriger Ebene eignen sich zum Abfragen, nicht zur Installation. Verwende dafür apt oder dnf.

sudo apt remove / sudo dnf remove

Wozu dient es?
Entfernt ein Paket über den Paketmanager.
Wo wird es verwendet?
Wenn ein Testpaket nicht mehr benötigt wird.
Warum ist es wichtig?
Paketdatenbank und Abhängigkeiten werden kontrolliert aktualisiert.
sudo apt remove cowsay

dpkg -l / rpm -qa

Wozu dient es?
Fragt die Liste installierter Pakete ab.
Wo wird es verwendet?
Zum Prüfen, ob ein Paket installiert ist.
Warum ist es wichtig?
Der Installationsstatus wird aus der Paketdatenbank angezeigt.
rpm -qa | grep cowsay
⚠️ Achtung

Das Installieren oder Entfernen ändert das System. Übe nur in deiner eigenen VM; entferne keine kritischen Pakete wie kernel, systemd, SSH oder Netzwerkwerkzeuge. Prüfe die Bestätigungsliste.

Mach es in deiner VM

Die eigentliche Praxis findet auf echtem Linux statt: Führe die Befehle in deiner eigenen virtuellen Maschine (VirtualBox, UTM oder WSL) aus und vergleiche die Ausgabe.

Installation und Entfernung ändern das System. Arbeite nur in deiner eigenen Test-VM, nicht auf einem Produktionssystem, und lies Bestätigungsdialoge immer sorgfältig.

Distribution erkennen

Prüfe die Distributionskennung und die verfügbaren Paketwerkzeuge.

cat /etc/os-release
command -v apt
dnf --version

Beispiel der erwarteten Ausgabe

Die Zeile ID= zeigt die Distribution; apt oder dnf ist für deine Familie verfügbar.
Meine Ausgabe sieht anders aus
  • Es müssen nicht beide Paketmanager vorhanden sein; nutze den passenden.
  • ID oder ID_LIKE hilft bei der Bestimmung der Distributionsfamilie.

Paket vor der Installation prüfen

Zeige zuerst Informationen über das Paket cowsay an. Führe nur den passenden Befehl für deine Distribution aus.

apt-cache policy cowsay

Beispiel der erwarteten Ausgabe

Candidate oder Paketversion
dnf info cowsay

Beispiel der erwarteten Ausgabe

Available Packages oder Paketinformationen
Meine Ausgabe sieht anders aus
  • Verwende apt-cache unter Debian/Ubuntu und dnf unter Rocky/Alma/Fedora.
  • Wird das Paket nicht gefunden, sind eventuell Paketlisten veraltet oder das Repository nicht aktiviert.

Testpaket installieren

Installiere das kleine Paket cowsay nur in deiner eigenen Test-VM mit dem passenden Befehl. Prüfe die Änderungen im Bestätigungsdialog.

sudo apt install cowsay

Beispiel der erwarteten Ausgabe

Setting up cowsay oder Installation abgeschlossen
sudo dnf install cowsay

Beispiel der erwarteten Ausgabe

Complete! oder Installed: cowsay
Meine Ausgabe sieht anders aus
  • Führe nur einen Block aus: apt für Debian/Ubuntu, dnf für die RHEL-Familie.
  • Wenn das Paket nicht gefunden wird, prüfe zuerst Repository und Paketnamen, statt die Installation zu erzwingen.

Testpaket entfernen

Entferne cowsay nach dem Test mit demselben Paketmanager und prüfe das Ergebnis. Lies die Liste der zu entfernenden Pakete vor der Bestätigung.

sudo apt remove cowsay

Beispiel der erwarteten Ausgabe

Removing cowsay oder cowsay wurde entfernt
sudo dnf remove cowsay

Beispiel der erwarteten Ausgabe

Removing: cowsay oder Complete!
Meine Ausgabe sieht anders aus
  • Verwende nur den Befehl der Distributionsfamilie, mit der du das Paket installiert hast.
  • Wenn unerwartete wichtige Pakete aufgeführt werden, bestätige nicht; brich mit n ab.

Selbsttest

Welches übergeordnete Paketwerkzeug wird üblicherweise auf Ubuntu und Debian verwendet?

apt verwaltet auf Debian-Systemen Repositories und Paketinstallationen.

Wie heißt das Paket für Apache HTTP Server in der RHEL-Familie üblicherweise?

In der RHEL-Familie heißt es meist httpd, in der Debian-Familie apache2.

Was bewirkt apt update?

apt update erneuert lokale Repository-Indizes; für Paketupgrades brauchst du apt upgrade.

Was solltest du im Bestätigungsdialog einer Installation tun?

Die Abhängigkeitsauflösung kann weitere Pakete ändern; prüfe die Liste vor der Ausführung.

Zusammenfassung

  • Ubuntu/Debian: apt/dpkg; Rocky/Alma/Fedora: dnf/rpm. Prüfe Distribution und Paketnamen zuerst.
  • apt update erneuert Paketlisten; Installation und Upgrade sind getrennte Vorgänge.
  • Prüfe vor Entfernung und autoremove die vorgeschlagenen Änderungen und bewahre kritische Systempakete.

Fachbegriffe

repository
Softwarequelle, in der eine Distribution Pakete und Paketinformationen veröffentlicht.
dependency
Ein weiteres Paket, das ein Paket zum Installieren oder Ausführen benötigt.
package manager
Werkzeug zum Installieren, Aktualisieren und Entfernen von Paketen samt Abhängigkeiten.
